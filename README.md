# cf-workers-template

A Cloudflare Workers project template with Hono.

## Getting started

```bash
pnpm install
pnpm run dev
```

## Scripts

- `pnpm run dev` — Start local development server
- `pnpm run deploy` — Deploy to Cloudflare Workers
- `pnpm run check` — Run type checking and tests
- `pnpm run test` — Run tests
- `pnpm run typecheck` — Run TypeScript type checking
